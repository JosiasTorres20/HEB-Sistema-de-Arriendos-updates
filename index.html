Política de Privacidad

Sistema de Arriendos · JosiaStudio

Última actualización: 13 de septiembre de 2026

1. Responsable y contacto

El responsable del tratamiento de la información utilizada por el Sistema de Arriendos es JosiaStudio.

Para consultas relacionadas con privacidad, protección de datos personales o el funcionamiento del Sistema de Arriendos, puede comunicarse mediante el correo electrónico: jositoerr2332@gmail.com .

Esta política se aplica al uso del Sistema de Arriendos, una aplicación desarrollada y proporcionada por JosiaStudio para la gestión de clientes, herramientas, productos, arriendos, devoluciones, pagos y otras operaciones relacionadas.

JosiaStudio podrá acceder de manera limitada a información del sistema cuando sea necesario para proporcionar soporte técnico, mantenimiento o resolución de incidencias y cuando dicho acceso haya sido autorizado por la organización que utiliza el software.

2. Información tratada y procedencia

El Sistema de Arriendos puede registrar información proporcionada por clientes, representantes, trabajadores y usuarios autorizados, así como información generada durante las operaciones comerciales.

  • Clientes y contactos: nombre, razón social, RUT cuando corresponda, dirección, teléfonos, correo electrónico, persona de contacto, actividad comercial y antecedentes relacionados con la relación comercial.
  • Operaciones: contratos, herramientas o productos, cantidades, fechas, valores, descuentos, pagos, devoluciones, anulaciones y observaciones relacionadas con el servicio.
  • Evaluación comercial interna: clasificación, puntaje, estado del cliente y motivos relacionados con restricciones o bloqueos comerciales.
  • Usuarios del sistema: nombre, nombre de usuario, correo electrónico, rol, estado de la cuenta, accesos y determinadas acciones administrativas.
  • Conexión con Google: información necesaria para identificar la cuenta Google autorizada y tokens necesarios para mantener la autorización concedida por el usuario.

Las contraseñas utilizadas por los usuarios del Sistema de Arriendos no se almacenan como texto legible. El sistema utiliza mecanismos criptográficos para su verificación.

Los campos de observaciones deben utilizarse únicamente para registrar información pertinente a la relación comercial y al funcionamiento del servicio.

3. Finalidades del tratamiento

La información tratada mediante el Sistema de Arriendos puede utilizarse para las siguientes finalidades:

  • Identificar clientes, representantes y usuarios.
  • Gestionar solicitudes y contratos de arriendo.
  • Administrar herramientas, productos y disponibilidad.
  • Controlar entregas, devoluciones y atrasos.
  • Registrar pagos y antecedentes relacionados con los contratos.
  • Generar documentos, reportes y comprobantes operativos.
  • Gestionar cuentas de trabajadores y usuarios del sistema.
  • Controlar roles y permisos de acceso.
  • Proteger la seguridad y funcionamiento del sistema.
  • Enviar comunicaciones operativas cuando la función de correo haya sido habilitada.

La organización que utiliza el software es responsable de contar con las autorizaciones o fundamentos legales necesarios para recopilar y utilizar los datos personales ingresados en el sistema.

La utilización del software o la lectura de esta política no reemplaza las autorizaciones que puedan ser requeridas conforme a la normativa aplicable.

4. Google OAuth y Gmail API

El Sistema de Arriendos puede utilizar servicios proporcionados por Google para permitir el envío de comunicaciones operativas mediante una cuenta autorizada por el usuario.

La conexión se realiza mediante Google OAuth. El Sistema de Arriendos no solicita ni almacena la contraseña de la cuenta Google del usuario.

La aplicación utiliza el permiso gmail.send para permitir exclusivamente el envío de mensajes desde la cuenta que haya sido autorizada.

El Sistema de Arriendos no solicita acceso para leer la bandeja de entrada de Gmail mediante esta función.

Entre las comunicaciones que pueden enviarse se encuentran confirmaciones relacionadas con devoluciones, documentos asociados a operaciones y comunicaciones relacionadas con cuentas de usuarios del sistema.

Los destinatarios, contenido de los mensajes y archivos adjuntos enviados mediante Gmail API son procesados por Google conforme a sus propios términos y políticas.

El uso y la transferencia de información recibida mediante las API de Google se ajustarán a la Política de datos de usuario de los servicios de API de Google , incluidos sus requisitos de uso limitado.

La información obtenida mediante las API de Google no será utilizada para publicidad personalizada, venta de información ni para entrenar modelos generales de inteligencia artificial.

El usuario puede desconectar su cuenta Google desde las opciones disponibles en el Sistema de Arriendos cuando corresponda. También puede revocar el acceso concedido desde la configuración de seguridad y conexiones de terceros de su cuenta Google.

La revocación de la autorización no elimina mensajes que ya hayan sido enviados ni copias que puedan conservar sus destinatarios.

5. Almacenamiento, acceso y terceros

Los registros comerciales utilizados por el Sistema de Arriendos se almacenan en la base de datos MySQL configurada y administrada por la organización que utiliza el software.

La ubicación física o lógica de dicha base de datos depende de la infraestructura definida por cada organización que utiliza el Sistema de Arriendos.

Determinadas configuraciones, preferencias y credenciales necesarias para el funcionamiento de la aplicación pueden almacenarse localmente en el perfil de Windows del usuario.

Cuando corresponde, las credenciales y tokens almacenados localmente utilizan mecanismos de protección proporcionados por Windows, incluido Windows DPAPI.

El acceso a la información del sistema debe estar limitado a usuarios autorizados conforme a sus funciones y permisos.

Los documentos PDF, exportaciones, impresiones y respaldos generados a partir del sistema pueden contener datos personales y deben protegerse de acuerdo con su naturaleza y sensibilidad.

JosiaStudio no vende información personal.

La información podrá ser comunicada a proveedores necesarios para la prestación de servicios, destinatarios autorizados de documentos, proveedores tecnológicos o autoridades cuando exista una obligación o requerimiento válido.

Cuando se utilizan servicios como Google OAuth o Gmail API, determinados datos pueden ser procesados por Google mediante infraestructura ubicada fuera del país donde se encuentra el usuario. Dicho tratamiento se encuentra sujeto a las políticas y condiciones de Google aplicables a esos servicios.

La distribución de nuevas versiones del Sistema de Arriendos mediante GitHub u otros medios no requiere publicar bases de clientes, respaldos, contraseñas, credenciales ni documentos comerciales.

6. Conservación y eliminación

La información se conservará mientras resulte necesaria para cumplir las finalidades para las cuales fue recopilada y durante los períodos que correspondan de acuerdo con obligaciones legales, contractuales, administrativas o comerciales aplicables.

Categoría Criterio de conservación
Clientes y contactos Mientras exista una relación comercial o mientras la información resulte necesaria para obligaciones relacionadas con operaciones anteriores.
Contratos, pagos y devoluciones Durante el tiempo requerido para fines operativos, administrativos, contables, contractuales o legales.
Cuentas de trabajadores y auditoría Mientras la cuenta permanezca activa y posteriormente cuando los registros sean necesarios para fines de seguridad, auditoría o trazabilidad.
Respaldos De acuerdo con la política de respaldo y recuperación definida por la organización que administra la instalación.

La eliminación de una cuenta de usuario no implica necesariamente la eliminación inmediata de registros relacionados con arriendos, pagos, devoluciones o auditorías en los que dicho usuario haya participado.

La eliminación de información desde la base de datos activa tampoco elimina automáticamente copias existentes en respaldos, documentos impresos, exportaciones o mensajes de correo previamente enviados.

7. Seguridad

El Sistema de Arriendos incorpora diversas medidas destinadas a proteger la información y controlar el acceso al sistema.

  • Roles y permisos de usuario.
  • Protección criptográfica de las contraseñas de los usuarios.
  • Controles relacionados con intentos de autenticación.
  • Registro de determinadas acciones y operaciones.
  • Expiración de sesiones conforme a la configuración del sistema.
  • Protección local de determinadas credenciales mediante mecanismos proporcionados por Windows.

La organización que utiliza el Sistema de Arriendos debe complementar estas medidas mediante buenas prácticas de seguridad, incluyendo protección de los equipos, cuentas individuales, actualizaciones, respaldos y controles adecuados sobre el acceso al servidor MySQL.

Ningún sistema informático puede garantizar una seguridad absoluta. Ante un incidente de seguridad, deberán evaluarse sus efectos y adoptarse las medidas de contención, recuperación y comunicación que correspondan.
